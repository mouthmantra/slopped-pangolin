# Adwaita's hand cursors

`pointer`, `grab` and `grabbing` are the Xcursor files of GNOME's Adwaita
cursor theme, unchanged, from adwaita-icon-theme 51.0
(https://gitlab.gnome.org/GNOME/adwaita-icon-theme). Pangolin's theme
(`tool/cursors/generate.dart`) uses them for its hands.
